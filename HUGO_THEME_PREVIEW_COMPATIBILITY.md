# Hugo Theme Preview Compatibility

HugoInk theme preview is a safe approximation for writing and layout checks. It is not a complete Hugo runtime.

## Supported

- Site configuration discovery from root configuration files and `config/` fragments
- Repository and theme CSS, fonts, images, and static media through a repository-scoped read-only URL scheme
- Common page values: title, content, date, draft, type, section, layout, permalink, language, word count, reading time, summary, and scalar Front Matter parameters
- Project and theme `single.html`-style layouts, content types, language variants, and responsive preview widths
- `figure`, `ref`, `relref`, and basic `highlight` shortcode approximations
- Explicit placeholders for unsupported template expressions and shortcodes

## Approximated

- Markdown uses HugoInk's native block renderer, so generated IDs and some Goldmark extensions may differ
- `figure` output preserves the image, caption, and meaning but not every Hugo attribute or wrapper
- Date formatting, summary, reading time, and permalink expansion cover common cases rather than Hugo's full rules
- YouTube and Vimeo embeds remain visible placeholders because external frames are blocked

## Not compatible

- Go template control flow, variables, scratch values, partials, blocks, nested template inheritance, and custom functions
- Hugo Pipes, asset transforms, image processing, taxonomies, menus, data files, page collections, multilingual translation lookup, and module mounts
- Custom shortcode templates and paired shortcode body evaluation
- JavaScript execution, external network requests, forms, frames, objects, and files outside the selected repository

The XCTest fixture in `SyncMDTests/HugoThemePreviewFixture` compares a semantic snapshot against output generated by official Hugo v0.164.0. Add a focused fixture and document the remaining gap before expanding the supported subset.
